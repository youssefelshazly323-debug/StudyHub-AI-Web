# StudyHub AI — Website

The public website for StudyHub AI, an AI study partner built for South African university students. This repo contains the HTML pages required for Task 2, Phase 3 of the WIL module (XHAW5112).

## Pages

| File | Page | Description |
|---|---|---|
| `index.html` | Home | Landing page with hero section, feature highlights, and call-to-action. |
| `about.html` | About Us | Mission statement, what StudyHub does, and the team. |
| `contact.html` | Contact | Support contact card, FAQ accordion, and a message form. |
| `fees.html` | Fees | Pricing plans — Free, Student (R49/month), and Study Group (R129/month). |
| `signup.html` | Sign up / Log in | Tabbed authentication page (individual page requirement). |

## Design

- Colour palette: primary blue `#2F4EA0`, purple accent `#7B5FC4`, light grey background `#F5F6FA`.
- Consistent top navigation and button styles across every page so the site feels like one product.
- Responsive layout: pages adjust to a single column on smaller screens (under 900px wide).
