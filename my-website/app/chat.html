Can you explain why oligopolies are strategically interdependent, using a South African example?
StudyHub AIIn an oligopoly, only a few large firms serve the market, so each firm’s decisions affect the others. If one changes price, output or advertising, rivals must decide how to respond.

A useful example is South African mobile networks: a data-price change by one major network can prompt competing offers from others. Each firm anticipates those reactions before acting.
